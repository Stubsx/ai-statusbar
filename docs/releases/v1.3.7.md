相较 v1.3.6，本次更新：

- **新增 Claude Desktop 状态适配**：显示桌面应用在线状态，以及 Code 标签页会话的忙碌、结束和最近活动；支持官方与第三方登录配置目录，并避免同一会话在 Claude Code 和 Claude Desktop 中重复出现。普通聊天页仅显示应用在线状态。
- **支持 Kimi Code 1.1.0 工作区跳转**：点击会话可打开对应工作区并进入新对话；已开启调试桥接的用户仍沿用原有的会话恢复方式。
- **改善 Codex 会话标题与活动展示**：优先显示应用生成的简明标题，清理附件说明、AGENTS.md 等前导上下文；缺少标题时尝试从用户消息恢复。子代理结束或中断不再作为独立完成活动展示，运行中的子代理仍保留。
- **修复 Hermes 历史用量的模型归类**：对能够准确还原的同日历史记录补回模型名称，保持用量总数不变；无法确定归属的记录保留原值。
- **统一分发签名与本地安装**：App 和 DMG 使用 Developer ID 签名，启用 Hardened Runtime 与安全时间戳；本版本尚未经过 Apple 公证。安装成功后仅保留「应用程序」中的正式副本，减少 Spotlight 搜索到旧构建的问题。
