相较 v1.3.8，本次更新：

- **新增按会话显示 TPS**：状态页和原生菜单为每个会话展示最近一次已完成请求的速度。ZCode 支持生成与整轮平均速度；Kimi Code / Kimi Work 使用流式耗时计算生成速度；Codex 使用 `task_complete` 的 TTFT 显示有效速度，并一次性安全回填历史记录，不再用受工具执行时间影响的整轮平均凑数。请求明细仅保存在本机，默认保留 90 天，可在「设置 → 数据」调整保留期或单独清空，不影响长期每日用量，也不参与多设备同步。
- **增加每日费用图表**：近 7 天／30 天用量柱状图可切换 Token／费用并记住选择，悬停按当前币种显示当天金额；图表与明细增加独立切换按钮。
- **补充模型报价**：预估 API 费用新增 models.dev 公开目录，OpenRouter 报价优先，缺失模型可补充 Kimi K3.1 Pro 普通版与 Highspeed 的独立报价；报价、汇率获取和隐私边界保持不变。
- **完善 Kimi 桌面精确跳转恢复**：实验性跳转连接失败时明确提示，可改开工作区；仅在用户确认后重启 Kimi Code 并沿原会话 ID 重试，不自动重启、不循环重试，也不把失败伪报为成功。
