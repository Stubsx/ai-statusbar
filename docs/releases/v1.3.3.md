相较 v1.3.2，本次更新：

- 优化浮球眼睛跟随的响应：鼠标移动或拖动时立即唤醒，减少从静止状态开始移动时的迟滞。
- 修复缓慢移动鼠标时，眼睛因接近目标位置而过早降频、出现断续跟随的问题；停止移动后保留短暂的平滑收敛时间。
- 眼睛和眨眼改用原生图层绘制，并跟随显示刷新节奏更新，减少反复布局的开销；兼顾 macOS 12／13 的显示时钟支持。
- 优化主线程繁忙后的跟随恢复，按实际经过时间追赶当前位置，并合并旧系统上的待执行刷新，避免积压更新。
- 保留静止时低频检测、隐藏时停止跟随的节能行为；「设置 → 通用 → 低能耗模式」同样使用改进后的眼睛跟随。鼠标监听不记录轨迹、不上传位置，也不需要新增权限。
