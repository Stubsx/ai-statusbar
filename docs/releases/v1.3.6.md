相较 v1.3.5，本次更新：

- **新增 API 费用估算**：在「设置 → 数据 → 预估 API 费用」开启后，按 OpenRouter 公开模型报价计算费用，并通过 Frankfurter 汇率折算人民币。支持今日、近七日、近30日和本机／多设备汇总；功能默认关闭，报价和汇率请求不发送会话或用量。
- **用量面板支持人民币／美元切换**：直接显示所选币种的金额并记住选择，总计与模型明细使用一致的字号和字重。报价来源、汇率日期、计价覆盖率及计算说明集中在设置中的「详情」页；估算金额用于 API 标价参考，不代表订阅账单。
- **改善 ZCode 3.x 状态识别**：新输入开始执行时及时显示忙碌，后台提醒、压缩摘要和隐藏消息不再把已结束任务重新标成运行中。会话索引暂时不可读时可从主会话库恢复标题，退出后的短暂索引异常不再显示为工具故障。
- **修复 Hermes 用量的模型归类**：正确读取数据库中的模型名称，避免有明确模型记录的用量被归入「未知模型」。
