相较 v1.3.7，本次更新：

- **新增用量图表**：用量页可按工具或模型查看占比与图例；今日视图展示输入、缓存和输出构成，近 7 天／30 天视图增加每日用量柱状图。点击图表或明细列表即可双向切换，并记住当前视图。
- **重设计浮球视觉与动画**：晴蓝和水墨统一为干净静态色面、内缘柔光与单条工作轨道，替代水纹噪声和整球流动帧，减少纹理生成与长期帧缓存；保留视线跟随、眨眼、状态数字、休眠冻结和低能耗模式。
- **优化 DeepSeek Harness 跳转**：点击工具名称、会话行或单条通知时优先恢复官方桌面版，未安装或启动失败时回退本机 Web 页面。当前官方桌面版尚未提供按会话 ID 直达的外部接口，因此目标会话仍需在应用内选择。
- **修复 Codex 内部评审线程误报**：guardian 自动审批的内部步骤不再被当作 Codex CLI 会话，也不会进入最近任务、历史记录或触发完成通知。
- **合并 Kimi K3 用量记录**：Kimi Code 的 `k3`／`kimi-code/k3`、Hermes 的 `kimi-k3` 与 Kimi Work 的 `k3-agent` 在模型视图中统一归并，既有历史用量自动按新口径汇总，无需手动迁移。
