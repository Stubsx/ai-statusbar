相较 v1.3.3，本次更新：

- **修复 Kimi Code 桌面版运行状态漏报**：正确识别桌面主进程，模型思考期间即使没有文字或工具输出，也能根据未结束的请求显示运行。修复 Kimi Code 与 Kimi Work 的进程误识别，退出后不再因 Helper 或崩溃上报进程而保持在线。
- **改善 Kimi Code 跳转**：点击工具、任务或通知时优先打开已安装的 Kimi Code 桌面版，复用现有窗口；未安装或启动失败时回退到原有网页／宿主路径。
- **新增桌面版精确跳转（实验性）**：位于「设置 → 工具与连接 → Kimi Code」，默认关闭。启用后通过本机调试连接尝试打开指定会话，失败时仅打开应用。首次启用需退出 Kimi Code，再从灵眸打开；关闭开关后，需退出 Kimi Code 并正常启动才能关闭调试连接。该连接具有控制 Kimi 页面的能力，仅适合可信的本机环境。
- **整理设置入口**：各工具的专属选项、空闲时长、连接状态和账号配额集中到「工具与连接」；Kimi Work 月度额度授权归入对应分区，数量单位移到「数据」。现有配置保留，无需重新设置。
- **修复浮球动画中断后无法自行恢复的问题**：自动恢复被清除的流动和光圈动画；检测到播放停住时启用有限帧率的备用播放。隐藏、休息、低能耗模式及系统减少动态效果仍按原规则停播，后台帧准备完成不会重新启动已销毁的视图。
- **缩短流动效果的冷启动等待**：先使用轻量循环开始流动，再保持进度切换到完整精度，保留晴蓝、水墨两种外观与原有循环速度。
- 改进安装包构建中的采集器路径定位，确保打包的是当前工具链本次编译的产物。
