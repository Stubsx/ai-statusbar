相较 v1.3.0，本次更新：

- **新增应用内更新**：启动时可在后台检查新版本，发现更新后提醒；在「设置 → 通用」点击「立即更新」，即可下载安装包、校验后替换并重启。可关闭自动检查，安装仍由用户主动触发。
- **降低常驻开销**：优化浮球工作光环、鼠标静止时的检测和后台状态刷新，减少持续界面重绘与重复扫描；移除灵眸自身阻止系统自动休眠的声明。
- **改善配额读取失败时的展示**：按小时、周、月窗口分别判断快照新鲜度；暂时读取失败时保留仍有效的历史快照，以弱化样式和时间提示区分旧数据。登录失效、关闭在线配额或窗口已过期时不展示旧快照。
- **修复 Hermes 跳转**：优先打开本机已安装的 Hermes 桌面端，避免误开同名安装器。
